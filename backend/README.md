# Project Management – Backend (Skeleton)

## Estrutura de Clean Architecture

```
backend/
├─ src/
│  ├─ controllers/   # Controllers (HTTP layer)
│  ├─ services/      # Business logic
│  ├─ routes/        # Route definitions
│  ├─ models/        # Entidades / modelos de domínio
│  └─ app.js         # Configuração do Express
├─ tests/            # Testes unitários/integrados
└─ package.json      # Dependências Node.js
```

Esta estrutura será preenchida nas próximas fases (API, banco, etc.).
